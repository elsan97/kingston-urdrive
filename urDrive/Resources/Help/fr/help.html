Kingston urDrive Help

Bienvenue

L'écran de bienvenue affiche une description urDrive de l'application urDrive et contient une vidéo d'introduction.

Il est doté d'un sélecteur de langue qui permet à l'utilisateur de choisir l'affichage dans leur langue préférée.

Navigation principale

a. Principal : Zone d'affichage du bureau qui contient une liste des raccourcis vers diverses applications, fichiers et sites Internet.

b. Dock d'accès rapide : Utilisé pour accéder aux fonctions principales ; Mes fichiers, Mes photos, Mes vidéos, Nouveautés, urAppZone, et Aide en bas de l'application.

c. Compteur de capacité : Affiche la capacité de stockage actuel de la clé USB.

d. Icône urFooz : L'utilisateur peut entrer dans le compte urFooz et afficher l'icône de l'avatar urFooz correspondant.

Mes fichiers

Mes fichiers affiche les fichiers et les dossiers stockés sur la clé USB.

Mes photos

Mes photos affiche les images JPEG stockées dans le dossier photo de l'utilisateur de la clé.

L'utilisateur a l'option de créer des albums photo et de les afficher sous forme de diaporama.

Ma musique

Ma musique affiche les fichiers MP3 stockés dans le dossier musique de l'utilisateur de la clé.

L'utilisateur peut écouter le contenu audio en ouvrant le fichier corresponsant qui est lu dans le lecteur de musique urDrive.

Mes vidéos

Mes vidéos affiche les fichiers vidéo stockés dans le dossier vidéo de l'utilisateur de la clé.

L'utilisateur peut voir le contenu vidéo en ouvrant le fichier correspondant qui s'ouvre ensuite dans le lecteur vidéo externe par défaut de l'ordinateur.

urAppZone

Naviguez, achetez ou obtenez des applications ou des contenus depuis urAppZone. La connexion au compte utilisateur urFooz est requise.

Nouveautés

La section Nouveautés affiche les dernières offres et contenus promotionnels de Kingston et ses partenaires.

Merci de la consulter fréquemment afin de ne pas manquer d'offres spéciales.

Mes Apps

Naviguez et lancez des apps téléchargées depuis urAppZone.

Types de fichiers

Mes photos

Les types de fichiers supportés qui peuvent être affichés dans Mes photos sont:

  • .jpeg
  • .jpg
  • .bmp
  • .gif
  • .cdr
  • .psd
  • .jpg

* les fichiers non supportés ne s'afficheront pas dans Mes photos mais il est possible de les voir et d'y accéder dans Mes fichiers.

Ma musique

Les types de fichiers supportés qui peuvent être affichés dans Ma musique sont:

  • .mp3

* les fichiers non supportés ne s'afficheront pas dans Ma musique et ne seront pas lus dans le lecteur de musique urDrive mais il est possible de les voir et d'y accéder dans Mes fichiers.

Mes vidéos

Les types de fichiers supportés qui peuvent être affichés dans Mes vidéos sont:

  • .avi
  • .asf
  • .mpeg
  • .mpg
  • .wmv
  • .rmvb
  • .rm
  • .dat
  • .mp4
  • .mov

* les fichiers non supportés ne s'afficheront pas dans Mes vidéos mais il est possible de les voir et d'y accéder dans Mes fichiers.

Aide

Consultez la documentation d'aide ou changez la langue d'affichage préférée dans la section Aide.

Pour plus d'informations sur urDrive, merci de consulter: www.kingston.com/support/urDrive
