Kingston urDrive Help

Welcome

The welcome screen displays feature description of Kingston urDrive application and it contains a instructional video.

There is a language selector that allows user to switch to their preferred language display.

Main Navigation

a. Main: Desktop display area that contains a list of shortcuts to a variety of applications, files and websites.

b.Quick Access Dock: Used to access main features; My Files, My Photos, My Music, My Videos, What’s New,     urAppZone, and Help at the bottom of the application.

c. Capacity Meter: Displays current storage capacity of the USB drive.

d. urFooz Icon: User can sign into urFooz account and display the corresponding urFooz avatar icon.

My Files

My File displays all documents and other files stored on the drive’s user file folder.

My Photo

My Photo displays JPEG images stored on the drive’s user photo folder.

User will have the option to create photo albums and display in slide show format.

My Music

My Music displays MP3 files stored on the drive's user music folder.

User can listen to the audio content by opening the corresponding file, which plays in the urDrive music player.

My Video

My Video displays video files stored on the drive’s user video folder.

User can view the video content by opening the corresponding file, which opens the external video player.

urAppZone

Browse, purchase or obtain application or content from urAppZone. urFooz user account login is required.

What's New

What’s New section display the latest offer and promotional content from our partners and us.

Please check it frequently and don’t miss out on special offers.

My Apps

Browse and launch apps downloaded from urAppZone.

File Types

My Photos

The supported file types that can be displayed in My Photos are:

  • .jpeg
  • .jpg
  • .bmp
  • .gif
  • .cdr
  • .psd
  • .jpg

* unsupported file types will not display in My Photos, but can be viewed and accessed in My Files.

My Music

The supported file types that can be displayed and played in My Music are:

  • .mp3

* unsupported file types will not display in My Music or play in the urDrive music player, but can be viewed and accessed in My Files.

My Videos

The supported file types that can be displayed in My Videos are:

  • .avi
  • .asf
  • .mpeg
  • .mpg
  • .wmv
  • .rmvb
  • .rm
  • .dat
  • .mp4
  • .mov

* unsupported file types will not display in My Videos, but can be viewed and accessed in My Files.
