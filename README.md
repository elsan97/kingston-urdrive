# Kingston urDrive v1.2.0.131 (Original Dump)

Оригинальный дамп утилиты **Kingston urDrive версии 1.2.0.131**, сохраненный с оригинального USB-накопителя **Kingston DataTraveler 102**. 

This is an authentic software dump of the dead **Kingston urDrive (v1.2.0.131)** launcher taken directly from a vintage **DataTraveler 102** USB flash drive.

## 📌 О софте / About
urDrive — это интерактивная WPF-оболочка со встроенным локальным рекламным баннером, кастомным проводником и экосистемой приложений, выпускавшаяся Kingston на рубеже 2010-2011 годов. Проект официально мертв и закрыт более 10 лет назад, официальные сервера отключены. Данный дамп представляет интерес для цифровых археологов и любителей ретро-ПО.

## ⚠️ Критически важно / Important Note
* **НЕ НАЖИМАЙТЕ кнопку "Auto Update" (Обновление)** внутри программы! Программа попытается проверить низкоуровневые дескрипторы привода. Если вы запустили её не с оригинальной флешки Kingston (например, с системного SSD/HDD), апдейтер заблокирует программу с ошибкой: *"Нет полномочий выполнять эту программу на данном приводе"*.
* **DO NOT click the "Auto Update" button!** It will trigger a hardware check. If run from a modern SSD or non-Kingston drive, it will permanently lock the app on that machine until you clear the AppData cache.

## 🚀 Как запустить на современном ПК / How to Run
1. Скачайте репозиторий (Code -> Download ZIP) и распакуйте в любую папку.
2. В первый раз запускайте `urDrive.exe` **с отключенным интернетом**, чтобы заблокировать фоновые запросы апдейтера.
3. Программа способна успешно игнорировать тип накопителя и масштабировать свой WPF-интерфейс на современные SSD большого объема.
